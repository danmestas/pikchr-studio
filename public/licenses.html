Pikchr Studio

Licenses

Pikchr Studio ships a WebAssembly build of the Pikchr renderer (pikchr.wasm and its loader pikchr.js). That build contains the third-party software below. The source for Pikchr Studio itself is at github.com/danmestas/pikchr-studio and is released under the same Zero-Clause BSD license as Pikchr (LICENSE).

Pikchr

Diagram language and renderer by D. Richard Hipp. pikchr.org. Pikchr Studio adds an opt-in authoring API on top of it; those changes are published as vendor/studio.patch in the repository.
